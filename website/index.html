GitHub

Attach source code as an archive

Attach a GitHub repository's source code to the current ChatGPT conversation as a ZIP file. Choose a repository, then optionally select a branch and/or a commit.

Attachment menu
Add an option to the + menu next to the message composer.
Slash command
Offer the repository attachment option when typing /attach-github-source in the composer.

Private repository access

 Not configured

By default, you cannot read from private repositories without authorization. Provide authorization for GPT Tweaks' GitHub-related utilities by adding a personal access token.

Create a fine-grained token on GitHub. Select the repositories it can access and grant Contents: Read-only permission.

Conversation

Context tracker

Show a progress bar above the ChatGPT message composer with estimated token usage and the number of messages in the current conversation.

Visibility

Show by default
Display the tracker when opening a conversation. When off, open it from the + menu or with /status.
Attachment menu
Add a Status option to the + menu next to the message composer.
Slash command
Use /status to show or hide the tracker.

Information shown

Estimated percentage used
Show the percentage of the token target used.
Estimated tokens used
Show the estimated token count for the current conversation.
Configured token target
Show the target token count alongside the estimated tokens used.
Message count
Show the number of messages in the current conversation.

Token usage target

Used to calculate the progress bar and percentage. This does not limit ChatGPT's actual context window.
