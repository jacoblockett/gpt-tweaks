Conversation

Completion notifications

Show a desktop notification and play a short sound when a final response finishes while ChatGPT is not focused. Click the notification to return to its browser tab.

Copy entire chat

Copy the complete conversation as Markdown. History loads only when selected; individual message Copy buttons remain native.

Session handoff

Use Session Handoff in the GPT Tweaks menu to generate a text-only Markdown handoff, then continue in a new chat in this tab. The handoff is transferred directly as composer text; no file is created or attached. Project conversations stay in their project.

Token Estimator

Automatically show the estimated token count in the center of the ChatGPT header.

GitHub

GitHub account

Not connected

Connect your GitHub account to allow GitHub-related utilities to read from your private repositories.

Attach source code as an archive

Attach a GitHub repository's source code to the current ChatGPT conversation as a ZIP file. Choose a repository, then optionally select a branch and/or a commit.

Repository history

Previously attached repositories appear in the attachment selector for quick reuse. Individual entries can also be removed there.
